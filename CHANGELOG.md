# Changelog

All notable changes to GuildLens. The text of this file goes into each release's notes.

## 0.1.0 — 2026-11-16

First release, for Classic Era and Classic Forever.

- Right-click a guildmate's name in guild chat, in the guild window's member list or in the guild window's own chat:
  at the end of the menu, their class (in its colour, with its icon) and level, race, guild rank, status (online,
  away, busy, or when they were last seen), zone, professions and public note. The game's own menu items stay as
  they are.
- Guild chat can show the sender's class icon, level and zone in place of `[Guild]`, each by its own option; all
  are off by default.
- The options window: `/glens`, or the AddOns tab of the game options. `/glens help` lists the commands.
- English and Russian; in Russian the default guild rank names are translated and races are named by sex where the
  game tells it.
- Nothing is sent anywhere: everything comes from what the client already knows about the guild.
